## 🚀 Featured Projects

### 🌾 [FarmBridge — Farmer-to-Buyer Marketplace](https://github.com/hariprasaddev/FarmBridge)
**A role-based marketplace connecting farmers directly with buyers — deployed and live in production.**

<p>
  <img src="https://img.shields.io/badge/Status-Live-brightgreen?style=flat-square" alt="Live"/>
  <img src="https://img.shields.io/badge/Endpoints-74-blue?style=flat-square" alt="74 Endpoints"/>
  <img src="https://img.shields.io/badge/Tests-60%2B%20passing-success?style=flat-square" alt="60+ Tests Passing"/>
</p>

- Designed a layered architecture (Controller → Service → Repository) with **74 REST API endpoints** across 15 controllers — Authentication, Products, Orders, Reviews, Wishlist, Notifications, and Admin modules
- Implemented **JWT-based stateless authentication** with Spring Security, enforcing role-based access control (RBAC) for Admin, Farmer, and Buyer roles with BCrypt password hashing
- Built product CRUD with **Cloudinary-backed image storage**, order placement with stock validation and status workflows, purchase-verified reviews, wishlist, and email + in-app notifications
- Delivered a **farmer verification workflow** (document submission → admin approval) and role-based analytics dashboards
- **Containerized** with Docker (multi-stage builds) and Docker Compose; automated with a **GitHub Actions CI/CD** pipeline running 60+ backend integration tests
- Deployed to production on **Render**, independently diagnosing and resolving real deployment issues: a CORS misconfiguration, a Docker build path error, a database connection pool timeout, and a Cloudinary SDK compatibility bug
- APIs documented with **Swagger/OpenAPI**, validated with **Postman**

**🔗 [Live Demo](https://farmbridge-frontend.onrender.com)** &nbsp;|&nbsp; **📂 [Source Code](https://github.com/hariprasaddev/FarmBridge)**
